## ADDED Requirements

### Requirement: Home page tech section provides a Journey action
The home page SHALL provide a clear action button in the tech section that navigates to the Journey page.

#### Scenario: Journey action is present and correct
- **WHEN** the visitor views the tech stack section
- **THEN** a button links to `/journey`.

### Requirement: Home page future section provides a Cool Tools action
The home page SHALL provide a clear action button in the future section that navigates to the Cool Tools page.

#### Scenario: Cool Tools action is present and correct
- **WHEN** the visitor views the future view section
- **THEN** a button links to `/tools`.

### Requirement: Section action controls are minimalist and readable
Section action controls SHALL follow the home page minimalist/professional style and remain clearly visible on the dark theme.

#### Scenario: Section action controls are readable
- **WHEN** the visitor scans section actions
- **THEN** controls are legible, clickable, and visually consistent with the black-first theme.
