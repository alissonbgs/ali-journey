## ADDED Requirements

### Requirement: Home page uses a black-first cosmic color palette
The home page SHALL use a black-dominant visual palette with dark-purple accents across surfaces and decorative elements.

#### Scenario: Black-first palette is applied
- **WHEN** the visitor opens the home page
- **THEN** the primary background and section styling appear predominantly black with restrained dark-purple accenting.

### Requirement: Universe/starfield identity is preserved
The home page SHALL preserve the existing universe concept, including visible stars and cosmic atmosphere.

#### Scenario: Stars remain visible after theme refresh
- **WHEN** the updated home page background is rendered
- **THEN** star elements remain visible and recognizable as part of the universe visual identity.

#### Scenario: Cosmic atmosphere remains present
- **WHEN** the visitor scans the page background
- **THEN** the background retains nebula/glow-like cosmic texture rather than a flat solid color.
