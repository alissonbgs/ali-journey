## Why

The Cool Tools page currently shows a single card, which makes the grid feel sparse and doesn't signal upcoming tools. Adding a second card balances the layout and sets expectations for future tools.

## What Changes

- Add a second card to the Cool Tools grid for the Video Suggestion tool.
- The second card is labeled "Video Suggestion" with a short description.
- The second card is non-interactive until the external repo link is ready.

## Capabilities

### New Capabilities
- `cool-tools-gallery`: The Cool Tools page presents a consistent set of tool cards, including the Video Suggestion tool.

### Modified Capabilities
- None.
